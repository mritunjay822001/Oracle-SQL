# DRL (Data Retrieval Language)

This folder contains Oracle SQL Data Retrieval Language (DRL) commands used to retrieve data from one or more database tables.

## Commands Covered

- SELECT

## Clauses Covered

- WHERE
- DISTINCT
- ORDER BY
- GROUP BY
- HAVING
- FETCH
- OFFSET
- Aliases

## Description

DRL is used to retrieve data from database tables. The SELECT statement, along with its clauses, helps filter, sort, group, and display data efficiently.

## Folder Contents

- Theory Notes
- Syntax
- Examples
- Practice Questions
- Interview Questions

## Learning Objectives

- Retrieve data using SELECT.
- Filter records using WHERE.
- Sort data using ORDER BY.
- Group data using GROUP BY.
- Filter grouped data using HAVING.
- Eliminate duplicate records using DISTINCT.

- Oracle Database
