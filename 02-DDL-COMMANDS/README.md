# DDL (Data Definition Language)

This folder contains Oracle SQL DDL (Data Definition Language) commands used to create, modify, rename, and delete database objects.

## Commands Covered

- CREATE
- ALTER
- FLASHBACK
- DROP
- TRUNCATE
- RENAME
- PURGE

## Folder Contents

- Theory Notes
- Syntax
- Examples
- Practice Questions
- Interview Questions

## Learning Objectives

- Understand the purpose of DDL commands.
- Create and modify database objects.
- Manage tables and other schema objects.
- Learn the differences between DROP, TRUNCATE, and DELETE.

## Tools Used

- Oracle Database
- SQL*Plus
- EditPlus
