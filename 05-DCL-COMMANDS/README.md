# DCL (Data Control Language)

This folder contains Oracle SQL Data Control Language (DCL) commands used to control user access, permissions, and security within the database.

## Commands Covered

- GRANT
- REVOKE

## Description

DCL commands are used to manage database security by granting or revoking privileges from users and roles. These commands ensure that only authorized users can access or modify database objects.

- Revoke privileges when required.
