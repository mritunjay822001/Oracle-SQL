# DML (Data Manipulation Language)

This folder contains Oracle SQL Data Manipulation Language (DML) commands used to insert, update, delete, and manipulate data stored in database tables.

## Commands Covered

- INSERT
- UPDATE
- DELETE
- MERGE
- INSERT ALL

## Description

DML commands are used to manipulate the data stored in database tables. They allow users to add new records, modify existing records, remove unwanted data, and synchronize data between tables.
