# TCL (Transaction Control Language)

This folder contains Oracle SQL Transaction Control Language (TCL) commands used to manage transactions in a database.

## Commands Covered

- COMMIT
- ROLLBACK
- SAVEPOINT
## Description

Transaction Control Language (TCL) is used to control and manage database transactions. These commands help make changes permanent, undo changes when necessary, create savepoints within a transaction, and define transaction properties.

## Learning Objectives

- Understand database transactions.
- Use COMMIT to save changes permanently.
- Use ROLLBACK to undo changes.
- Create SAVEPOINTS within a transaction.
- Control transactions using SET TRANSACTION.
