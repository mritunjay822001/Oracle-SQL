# User Management

This folder contains Oracle SQL user management commands used to create, modify, secure, and manage database users.

## Topics Covered

- CREATE USER
- ALTER USER
- Change User Password
- Lock User
- Unlock User
- DROP USER
- View Existing Users

## Description

User management is an important part of Oracle Database administration. It allows database administrators to create user accounts, modify account properties, manage passwords, and control user access.
